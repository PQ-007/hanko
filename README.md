# Hanko — *Verba non Acta*

Япон үг цээжлэх туслах browser extension, дагалдах вэбсайттай. Япон текст уншиж байхдаа таалагдсан үгээ өөрийн **багц / deck**-даа хадгалаад, **Anki** руу экспортолно. Бүх UI **монгол хэл** дээр, утгыг нь **монгол руу** автоматаар орчуулна.

## Юу хийдэг вэ

- **Үг хадгалах** — дурын хуудаснаас текст сонгоод япон үг
  багцдаа хадгална. Дуудлага, англи утга нь Jisho-оос, монгол орчуулга нь
  Google Translate-ээс автоматаар бөглөгдөнө.
- **Толь бичгийн хэлбэрт автоматаар оруулах (普通形)** — хувирсан үг (ж: 担っています) хадгалахад
  Jisho-ийн тусламжтайгаар үндсэн хэлбэрт нь (担う) автоматаар хөрвүүлнэ.
- **Anki руу экспорт** — `.apkg` файл (дуудлагын аудио шигтгэсэн) эсвэл
  `.txt` файл татаж аваад Anki-д импортлоно.
- **Багц зохион байгуулалт** — вэбсайт дээр **хавтас** үүсгэж, багцуудаа чирч
  (drag & drop) ангилна. **Хайлт**-аар бүх үгсээ шүүнэ.
- **Олон төхөөрөмж хооронд синк** — Google-ээр нэвтэрвэл багцууд бүх browser/
  дээр синк хийгдэнэ.

## Хэрхэн ашиглах вэ? (extension)

1. Ердийнхөөрөө япон текст уншиж байхад хайх үгээ select-лэнэ.
2. Үг хадгалахдаа текстээ сонгоод дараахын аль нэгийг:
   - **right mouse** дараад, багцад хадгалахыг сонгох, эсвэл
   - **Ctrl+Shift+L** дарна.
3. Жижиг цонх гарч ирэн дуудлага, утга, **монгол** орчуулга нь бэлэн
   бөглөгдсөн байна. Англи утгыг засаад **Enter** дарвал монгол орчуулга
   шинэчлэгдэнэ. Багцаа сонгож **Үг хадгалах** дарна.
4. PDF болон `file://` хуудсан дээр ижил маягийн **тусдаа цонх** нээгдэнэ.
5. Өргөтгөлийн цонхон дахь **Вэб дээр засах** товч нь вэб засварлагчийг (бүх
   функцтэй) шинэ табд нээнэ.

## Chrome дээр суулгах

1. `chrome://extensions` → баруун дээд **Developer mode** асаах.
2. **Load unpacked** → `chrome/` хавтсыг сонгох.

## Firefox дээр суулгах

1. `about:debugging#/runtime/this-firefox`.
2. **Load Temporary Add-on…** → `firefox/manifest.json`.
3. Анхаар: түр суулгасан extension Firefox-ийг хаахад устдаг.

## Багцаа удирдах вэбсайт

`web/` доторх Next.js + Supabase вэб (**хар-цагаан** загвартай):

- **Google-ээр нэвтрэх** → багцууд таны бүртгэлд хадгалагдана.
- **Карт / Жагсаалт** харагдац. Карт нь дээр нь hover хийхэд **эргэдэг**
  (flashcard): урд талд үг + дуудлага, ард талд монгол + англи утга.
- **Үг засах (modal)** — карт дээр дарж засна. Англи утгыг засахад монгол
  орчуулга автоматаар шинэчлэгдэнэ (монголыг засахад буцаагаад орчуулдаггүй).
  **Jisho-оос дахин хайх** товчоор тохирох үр дүн дахин татна.
- **Хавтас** — drag & drop-оор багцыг хавтас руу оруулах/гаргах; folder→deck
  модны бүтэцтэй sidebar.
- **Хайлт** — үг/дуудлага/англи/монголоор бүх үгээс хайна.
- **Шинэчлэх** товч — өргөтгөл/өөр төхөөрөмжөөс нэмсэн үгсийг дахин ачаална.
- **Экспорт** — `.apkg` (аудиотай) болон `.txt`.
- **Дуудлага** — үг бүрд аудио үүсгэж сонсоно.

## Anki руу экспортлох

Багц сонгоод **`.apkg татах`** дарна → Anki-д **File → Import**. (Урд тал:
`үг (дуудлага)`, Ард тал: англи + монгол утга.) `.txt` нь tab-аар тусгаарласан:
`үг (дуудлага)    утга    шошго`.

## Нэвтрэх ба синк хийх

1. `chrome/config.js`, `firefox/config.js` дотор Supabase URL, publishable key,
   вэбсайтын хаягийг (`SITE_URL`) бөглөнө (production-д Vercel хаяг).
2. Өргөтгөлийн **Нэвтрэх** дарна → вэбсайтын `/extension/connect` хуудас табд
   нээгдэж Google-ээр нэвтэрнэ → session-ийг content-script гүүр дамжуулж
   background-д хадгална.
3. Нэвтэрсний дараа өргөтгөл болон вэбсайт ижил бүртгэлээр синк хийгдэнэ.
   Нэвтрээгүй үед өргөтгөл зөвхөн локалаар (storage.local) ажиллана.

## Тэмдэглэл

- Jisho болон Google Translate-ийн нийтийн (түлхүүргүй) endpoint ашиглана.
  Унтарвал талбарууд хоосон үлдэх ба гараар бичиж болно.
- Гарын товчлолыг (`Ctrl+Shift+L`) `chrome://extensions/shortcuts` эсвэл
  Firefox-ийн тохиргооноос өөрчилнө.

## Төслийн бүтэц

```text
src/        өргөтгөлийн нийтлэг код (sync модуль, config жишээ)
chrome/     Chrome build (Manifest V3, service worker)
firefox/    Firefox build (Manifest V3, scripts background)
icons/      語 тамга дүрс (web favicon-д бас ашиглагдана)
web/        дагалдах вэбсайт (Next.js + Supabase, Tailwind)
supabase/   өгөгдлийн сангийн migration файлууд (decks/words/folders, RLS)
```

`web/` нь компонентоор салгагдсан: `app/decks/_lib/` (Supabase client, монгол
текст `T`, төрлүүд), `app/decks/_components/` (Sidebar, DeckHeader, DeckDetail,
WordRow, WordEditModal, AddWordForm, SearchResults).
