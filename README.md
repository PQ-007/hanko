# Hanko — *Verba non Acta*

Япон үг цээжлэх **spaced repetition (SRS)** систем. Таалагдсан үгээ хаанаас ч
хамаагүй цуглуулж, **багц / deck**-даа хадгалаад, өдөр бүр тоглоом шиг давтана.
Бүх UI **монгол хэл** дээр, утгыг нь **монгол руу** автоматаар орчуулна.

Гурван хэсэгтэй, бүгд **нэг Supabase төсөл** (нэвтрэлт, Postgres, Storage)
дээр ажиллана — аль нэгт нь нэмсэн үг, хийсэн давталт бусад дээр шууд харагдана:

| Хэсэг | Хавтас | Юунд |
| --- | --- | --- |
| **Browser extension** | `chrome/`, `firefox/` | Дурын хуудаснаас үг барьж авах |
| **Вэбсайт** | [`web/`](web/README.md) (Next.js) | Багц удирдах, давтах, статистик, тулаан |
| **Мобайл апп** | [`mobile/`](mobile/README.md) (Flutter) | Явж байхдаа давтах, камераар үг авах |

## Юу хийдэг вэ

### Үг цуглуулах

- **Extension** — япон текст сонгоод **right mouse** эсвэл **Ctrl+Shift+L**.
  Дуудлага, англи утга нь Jisho-оос, монгол орчуулга нь Google Translate-ээс
  автоматаар бөглөгдөнө. Хувирсан үгийг (担っています) толь бичгийн
  хэлбэрт (担う) нь хөрвүүлнэ.
- **Гараар нэмэх** (вэб + мобайл) — бичих зуураа Jisho-ийн үр дүнгүүд
  жагсаж харагдана, тохирохыг нь сонгоно. Уншиж чадах ч бичиж чадахгүй
  ханзаа **гараар зурж хайна** (вэб: Google-ийн танигч, мобайл: утсан дээрх
  ML Kit — интернэтгүй ажиллана).
- **Камер** (мобайл) — ном, дэлгэцний зураг авбал япон үгсийг таниад санал
  болгоно, сонгосноо нэг дор хадгална. Буруу багц руу орсон бол
  **Буцаах**-аар бүгдийг нь буцаана.

### Давтах

- **SRS хуваарь** — SM-2 + сурах алхам (1м / 10м), өдрийн хязгаар, өдөр
  шилжих цаг (өглөөний 4 цаг). Хуваарийг серверт (`review_card()`) нэг газар
  тооцдог тул вэб, мобайл хоёр хэзээ ч зөрөхгүй.
- **Мангас агнах** — 42 дүрийн дундаас мангастай тулах, 10 секундийн
  асуулттай давталт. Сурсан ханзаа бичиж хариулах асуулт ч гарна.
- **Энгийн карт**, **чөлөөт дасгал**, **leech rescue** (байнга мартдаг үгс).
- **Ханз бичих хичээл** — зурлагын дарааллаар дагаж, хагас харж, санаж бичнэ.
- **Аудио багц** (мобайл) — багцаа MP3 болгоод алхаж явахдаа сонсоно;
  хүсвэл үг бүрийн дараа жишээ өгүүлбэр, англи орчуулгатай нь.
- **Статистик** — идэвхийн хуанли, цуврал (streak, freeze-тэй), түвшний
  график, өсөлт.

### Бусадтай хамт

- **Найзууд** — handle-аар найзлах, XP / ELO, найзуудын leaderboard.
- **Нүүр тулах тулаан (PvP)** — урилгын кодоор эсвэл найзаа урьж тулна;
  хоёулаа ижил асуултанд хариулна. Тулааны өмнө ба дараа **чат**: дүрийн
  хөдөлгөөнтэй эмотикон, бэлэн үгс, найзтайгаа бичиж ярих. Вэб, мобайл
  тоглогчид хоорондоо тулна. Бот-той ч тоглож болно.
- **Багцаа хуваалцах** — 24 цагийн линк; хүлээн авагч бүртгэлгүйгээр картаар
  дасгал хийнэ, нэвтэрсэн бол өөртөө хуулна.
- **Story зураг** — өнөөдрийн үгс, амжилтаа Instagram story болгож хуваалцана.

### Мөн

- Гурван загвар: **Цайвар**, **Бараан**, **Цэнхэр** — вэб, мобайл,
  extension бүгд дээр (мобайлын дүрс хүртэл солигдоно).
- **Офлайн** (мобайл) — багцаа татаж аваад интернэтгүй давтана; хариултууд
  холбогдмогц илгээгдэнэ.
- **Anki руу экспорт** — `.apkg` (аудиотой) эсвэл `.txt`.

## Extension

### Суулгах

- **Chrome:** `chrome://extensions` → **Developer mode** асаах →
  **Load unpacked** → `chrome/` хавтас.
- **Firefox:** `about:debugging#/runtime/this-firefox` →
  **Load Temporary Add-on…** → `firefox/manifest.json`. (Түр суулгасан
  extension Firefox-ийг хаахад устдаг.)

### Ашиглах

1. Япон текст уншиж байхдаа үгээ сонгоод **right mouse → багцад хадгалах**
   эсвэл **Ctrl+Shift+L**.
2. Жижиг цонхонд дуудлага, утга, монгол орчуулга бэлэн байна. Англи утгыг
   засаад **Enter** дарвал монгол нь шинэчлэгдэнэ. Багцаа сонгоод хадгална.
3. PDF болон `file://` хуудсан дээр тусдаа цонх нээгдэнэ.
4. Өргөтгөлийн цонхонд өнөөдрийн давтах үгсийн тоо, бүх багцаас хайх, үг
   засах / устгах (буцаах боломжтой) байна. Дүрсэн дээрх тоо = өнөөдөр
   давтах үг.

**Нэвтрэх:** өргөтгөлийн **Нэвтрэх** → вэбсайтын `/extension/connect` хуудас
табд нээгдэж Google-ээр нэвтэрнэ. Нэвтрээгүй үед өргөтгөл зөвхөн локалаар
ажиллана. Тохиргоо: `chrome/config.js`, `firefox/config.js` (Supabase URL,
publishable key, `SITE_URL`).

Гарын товчлолыг `chrome://extensions/shortcuts` эсвэл Firefox-ийн
тохиргооноос өөрчилнө.

## Вэбсайт

```bash
cd web
npm install
npm run dev      # http://localhost:3000
npm test         # node --test, нэмэлт сангүй
```

`.env.local`-д Supabase URL, publishable key хэрэгтэй — дэлгэрэнгүйг
**[SETUP.md](SETUP.md)**-аас. Кодын бүтэц, санах зүйлс —
**[web/README.md](web/README.md)**.

## Мобайл апп

```bash
cd mobile
cp env.example.json env.json   # Supabase URL, key, Google client ID бөглөнө
flutter run --dart-define-from-file=env.json
flutter test
```

VS Code-ийн `.vscode/launch.json` мөн `env.json`-ийг ашигладаг. Кодын бүтэц —
**[mobile/README.md](mobile/README.md)**.

- **Google нэвтрэлт** — Android-д SHA-1 бүртгэсэн тусдаа OAuth client,
  Supabase-ийн redirect allow list-д deep link хэрэгтэй.
- **Release build** хийсний дараа заавал утсан дээр ажиллуулж шалгана — ML
  Kit-ийн R8 дүрмүүд (`android/app/proguard-rules.pro`) debug build дээр
  илэрдэггүй.
- **`flutter run` эхлэхгүй байвал:** өмнө нь release build суулгаад Бараан /
  Цэнхэр загвар сонгосон бол апп нүүрний дүрсээ сольж, `flutter run`-ийн
  нээдэг entry-г унтраасан байдаг. Аппаа нээгээд **Цайвар** загвар руу
  шилжүүлж гарвал засагдана (adb-ээр засах боломжгүй).

## Өгөгдлийн сан

`supabase/migrations/` дотор 30 migration бий. Supabase CLI ашигладаггүй —
**SQL editor-т дарааллаар нь гараар** ажиллуулна. Migration бүр дахин
ажиллуулахад аюулгүй. Хүснэгт бүр RLS-ээр хамгаалагдсан тул extension, мобайл
хоёр publishable key-гээр шууд REST-ээр ханддаг.

## Anki руу экспортлох

Багцын **⋯** цэснээс **`.apkg`** татаад Anki-д **File → Import**. (Урд тал:
`үг (дуудлага)`, ард тал: англи + монгол утга.) `.txt` нь tab-аар
тусгаарласан: `үг (дуудлага)    утга    шошго`.

## Төслийн бүтэц

```text
src/          extension-ий нийтлэг код (sync, UI) — chrome/, firefox/ руу хуулагдана
chrome/       Chrome build (Manifest V3, service worker)
firefox/      Firefox build (Manifest V3)
web/          вэбсайт (Next.js, Supabase, Tailwind)
mobile/       мобайл апп (Flutter, Riverpod, Drift)
supabase/     migration-ууд (схем, RLS, RPC функцууд)
icons/        語 тамга дүрс
```

Extension-д build алхам байхгүй: `src/sync.js`, `src/ui.js`-ийг засвал
`chrome/`, `firefox/` хоёуланд нь хуулна. `bash src/package.sh` хуулж,
хавтсууд зөрсөн эсэхийг шалгаад `web-ext-artifacts/` дотор zip үүсгэнэ.
Синкийн тест: `node src/sync.test.js`.
